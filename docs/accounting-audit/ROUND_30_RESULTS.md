- بوابات البطاقات: التقنيع، حالات المحاكاة الخمس، بقاء الفاتورة `unpaid` حتى الاعتماد، عدم مضاعفة الدفعة عند تكرار refresh، حرّاس المبلغ (0/تجاوز/بعد السداد).
- بوابة المورّد: قراءة مستنداته فقط، RFQ بردّ واحد، الرفع لا يُنشئ قيداً، AP ثابت.

## 6. قيود الأدلة
- الالتقاط تلقائي (Playwright) بصور كاملة الإطار بلا قص؛ كل صور «قبل» رُوجعت قبل وضع ماركر الاعتماد. ملفات `-response.json` لنداءات المصادقة مُنقَّحة (`***`) تلقائياً. D19 وE09b من API بلا شاشة (مسابر قراءة/تحديث حالة لا تنشئ مستندات).

## 8. التتبع والتنظيف والمتبقي (تقدير صريح)
- **التنظيف:** بيئة محلية معزولة؛ لا عكس للقيود (أدلة)؛ الحالة الختامية DB-039؛ إلغاء التكاملات = `PUT /payment-gateways/{geidea|neoleap} {active:false}` و`POST /payments/providers {provider:'moyasar', isActive:false}` (نفس نداء الإعداد) (لم يُنفَّذ كي تبقى الأدلة قابلة لإعادة القراءة؛ القاعدة تُسقط مع البيئة).
- **المغطّى الآن:** `apps/staff` (R10–R28)، `apps/bakery` (R29)، `apps/customer-portal` + روابط الدفع + بوابات البطاقات + بوابة المورّد (R30).
- **المتبقي داخل النطاق:** لا مسار تنفيذي مالي جديد معروف. **`apps/platform-admin`** = فوترة مشغّل المنصة (اشتراكات المستأجرين) لا محاسبة المستأجر؛ تقديرها: قراءة + تشغيل محلي قرائي في جلسة قصيرة إن طُلب، ولا تؤثر على أستاذ المستأجر. تبقى **جولة ختامية واحدة (R31) بلا تنفيذ**: التقرير الموحَّد (مصفوفة التغطية حسب الوحدة/الشاشة/التطبيق، تصنيف 163 + 49 عيباً حسب الشدة والمكوّن والجذر، قرارات السياسة المجمَّعة، خطة إعادة الاختبار بعد الإصلاح). تقدير الجهد: جلسة واحدة.
- **خارج النطاق (بلا تنفيذ ممكن محلياً):** النداء الحقيقي لميسر/جيديا/NeoLeap/Tap، ZATCA، Salla، OCR، التوقيع الإلكتروني، WhatsApp/البريد، تعدد العملات، إقفال السنة، الأصول الثابتة، تطبيقات marina/optics/fitment/tailoring.
